# ARI Discovery

- Runtime soportado: Node.js 20 o superior.
- El verificador obligatorio es `npm test`.
- Los tests no usan credenciales ni llamadas externas.
- Cada diagnóstico pertenece a un solo cliente y nunca comparte contexto o archivos con otro.
- El brief aprobado es obligatorio antes de iniciar la etapa 1.
- Las etapas avanzan en orden y requieren aprobación explícita.
- Los contratos JSON son la fuente de verdad. Si cambian, actualiza plantillas, fixtures y pruebas.
- No guardes secretos ni datos reales de clientes en Git.
- No hagas push, abras PR ni despliegues sin autorización explícita.
